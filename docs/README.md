# Evidencias del Taller 5

Esta carpeta debe contener las capturas tomadas desde DevTools y la app instalada:

- `manifest.png`: Application > Manifest sin errores.
- `service-worker.png`: Service Workers en estado activated and is running.
- `offline-catalog.png`: Network en Offline con el catálogo y el aviso de datos guardados.
- `installed-window.png`: aplicación instalada en ventana propia, sin barra de direcciones.

Las capturas se toman después de ejecutar `npm run dev` y abrir `http://localhost:3001`.
